## site:

指定站点内搜索。

```
Linux C 多线程 site:zhihu.com
```

## filetype:

指定文件格式搜索。

```
《UNIX 高级环境编程》filetype:pdf
```

## *

代替任何字符，模糊搜索。

```
通*符
守望**
```

## ""

完全匹配

```
"前端开源项目"
```

## -

排除关键字

```
套接字 -csdn
考研 -推广 -推广链接
```

## intitle

将搜索范围限定在标题中

```
PPT intitle:年终总结
```

## inurl

将搜索范围限定到 url 链接中

```
老友记 inurl:pan
```

## 《》

找电影、电子书

## intext

在网页中

```
老友记 intext:下载
```

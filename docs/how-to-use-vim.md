## 约定

1. `Ctrl` 键缩写为 `C`，`Alt` 键缩写为 `A`，`Shift` 缩写为 `S`。
2. 用连字符表示同时按下，例如 `C-r` 表示同时按下 `ctrl` 和 `r` 键，`C-r b` 表示同时按下 `ctrl` 和 `r` 键，松开两个键后按下 `b`。
3. 以 `:` 开始的命令需要输入 `<enter>`，例如 `:q` 实际上是 `:q <enter>`。

## Tips

VIM 常用的有三个模式：

- 正常模式 (Normal Mode)
- 插入模式 (Insert Mode)
- 命令模式 (Command Mode)

`word` -- 程序变量名、连续标点符号、连续汉字。

`+` -- 已修改。

`.` -- 可以重复上一次的命令。

`num<command>` -- 重复某个命令 `num` 次。

`10ivim ! ` -- 会重复插入 10 次 `vim ! `。

`3.` -- 重复 3 次上一个命令。

下面的命令也会执行复制操作。

- `d` -- 删除。
- `v` -- 可视化选择。
- `gU` -- 变大写。
- `gu` -- 变小写。
- `g~` -- 改变大小写。

## 打开 vim

`vim file -r ` -- 恢复上次异常退出的文件。

`vim file -R` -- 以只读的方式打开文件。

`vim file -M` -- 以真正只读的方式打开文件。

`vim file +` -- 打开文件，并定位到文件尾部。

`vim file +num` -- 打开文件，并定位到第 `num` 行。

`vim file +/pattern` -- 打开文件，并定位到第一个匹配到的位置。

`vim file -remote` -- 用已有的 vim 进程打开指定的文件。

`vim file1 [file2] [...]` -- 打开多个文件，显示 file1。

`vim -O[n] file1 file2 ...` -- 一次显示多个文件，并左右分屏显示。这里的 `n` 就是代表有几个文件需要分屏。

`vim -o[n] file1 file2 ...` -- 上下分屏。
## Insert Mode

`ESC` -- Back to Normal Mode.

`C-[` -- Back to Normal Mode

`:ab abbr phrase` -- 命令可以将一长串字符用缩写来定义。(abbreviate)，` abbr` 就是对 `phrase` 的简写，在 `insert` 模式中，输入 `abbr`，再按非字母字符（比如空格，点号等）Vim 就自动把 `phrase` 插入到光标处位置。 需要 set nopaste

`C-n` 、`C-p` -- 在当前缓冲区、其它缓冲区，以及当前文件所包含的头文件中查找以光标前关键字开始的单词。

`C-p` -- 向上查找以进行补全。(previous)

`C-n` -- 是向下查找以进行补全。(next)

`C-x C-l` -- 整行补全。(line)

`C-x C-d` -- 补全宏定义。(define)

`C-x C-v` -- vim 命令补全。(vim)

`C-x C-i` -- 根据头文件内关键字补全。(include)

`C-x C-f` -- 补全文件名。(filename)
    - 如果当前光标下的文本不包含任何路径信息，那么将显示当前目录下的文件列表。
    - 如果当前光标下的文本包含任何（绝对或相对）路径信息，那么将显示其指定目录下的文件列表。

`C-x C-o` --  全能补全。(Omni)，将由'omnifunc'选项指定的自定义函数来进行匹配。Vim将通过$VIMRUNTIME/autoload/{filetype}complete.vim文件来实现全能补全特性，现在支持8种语言，包括C, (X)HTML with CSS, JavaScript, PHP, Python, Ruby, SQL和XML。

补全文件名                      CTRL-X CTRL-F
补全宏定义                      CTRL-X CTRL-D
补全vim命令                     CTRL-X CTRL-V
用户自定义补全方式              CTRL-X CTRL-U
拼写建议                        CTRL-X CTRL-S

## Normal Mode

命令格式为： `operator [number] motion`
- `operator` - 操作符，代表要做的事，如 `d` （delete）代表删除。`c` （change）代表更改。
- `[number]` - 计数，代表重复的次数。
- `motion`   - 动作列表，在所操作的文本上的移动。

`h` -- left

`j` -- down

`k` -- up

`l` -- right

`i` -- 光标前，插入模式。(insert)

`I` -- 行首，插入模式。

`a` -- 光标后，插入模式。(append)

`A` -- 行尾，插入模式。

`o` -- 在当前行下方打开一个新行。(open)

`O` -- 在当前行上方打开一个新行。

`x` -- 删除光标所在处的字符。

`s` -- 删除光标所在处字符，并进入插入模式。相当于 `x i`。

`S` -- 删除当前行的文本，进入插入模式。相当于 `0 d$ i`。

`dd` -- 删除光标所在行，并将删除内容存到剪切板中。(delete)

`P` -- 粘贴剪切板内容到当前位置前。

`p` -- 粘贴剪切板内容到当前位置后。(paste)

`"+yy` -- 复制当前行到系统剪切板。

`"+p` -- 将系统剪切板内容粘贴到光标后面。

`"ayy` -- 复制当前行到寄存器 a。

`"ap` -- 将寄存器 a 中的内容粘贴到光标后面。

`ZZ` -- 保存并退出。

`w` -- 从当前光标直到一个单词起始处。(word)

`e` -- 从当前光标直到一个单词末尾。(end)

`W` -- 单词是由 `blank` 字符分隔开的字符串。从当前光标直到一个单词起始处。

`E` -- 单词是由 `blank` 字符分隔开的字符串。从当前光标直到一个单词结尾处。

`*` -- 匹配光标当前所在单词，移动光标到下一个匹配单词。

`#` -- 匹配光标当前所在单词，移动光标到上一个匹配单词。

`yw` -- 复制到下一个单词起始处。

`ye` -- 复制到下一个单词末尾。

`y2/foo` -- 复制两个 `foo` 之间的字符串。

`dw` -- 删除到下一个单词起始处。

`y$` -- 复制到行尾。

`d [num]w` -- 删除后 `num` 个单词。

`[num]dd` -- 删除下 `num` 行。

`de` -- 删除到下一个单词末尾处。

`d$` -- 删除到行尾。

`cw` -- 删除到下一个单词起始处，并进入插入模式。(change)

`ce` -- 删除到下一个单词结尾处，并进入插入模式。

`0` -- 移动到行首。

`^` -- 移动到本行第一个非 blank 字符处。

`$` -- 移动到行尾。

`g_` -- 移动到本行最后一个非 blank 字符处。

`u` -- 撤销。(undo)

`U` -- 撤销当前行所有修改。

`C-r` -- 取消撤销。(redo)

`/pattern` -- 正向搜索匹配 `pattern` 的字符串，支持正则表达式。

`?pattern` -- 反向搜索匹配 `pattern` 的字符串。
    - `n` -- 继续查找。
    - `N` -- 反向查找。
    - `C-o` -- 跳回到之前光标位置。
    - `C-I` -- 跳转到较新的位置。

`numG` -- 到第 `num` 行行首。

`:num` -- 同上。

`gg` -- 等同于 `1G` 或 `:1`。

`G` -- 到最后一行。

`r` -- 替换光标所在位置字符。

`R` -- 进入替换模式，替换模式和插入模式相似，不过每个输入字符都会删除已有字符。

`C-g` -- 显示光标及文件状态信息。

`H` -- 移动到当前屏幕第一行行首。(head)

`L` -- 移动到当前屏幕最后一行行首。

`C-f` -- 查看下一页内容。(front)

`C-b` -- 查看上一页内容。(back)

`C-u` -- 向上翻半页。(up)

`C-d` -- 向下翻半页。(down)

`~` -- 改变光标下的字母的大小写。

`g~~` -- 改变当前行字母的大小写。

`gUU` -- 改变当前行字母为大写。

`guu` -- 改变当前行字母为小写。

`%` -- 高亮配对的括号。

`F1` -- 显示 `help.txt`。

`ctrl + w  ctrl + w` -- 在窗口间跳转。

`ctrl + w s` -- 上下分割当前打开的文件。

`ctrl + w v` -- 左右分割当前打开的文件。

`Ctrl + w h` -- 将当前光标定位到左边的屏幕。

`Ctrl + w l` -- 将当前的光标定位到右边的屏幕。

`Ctrl + w j` -- 将当前光标定位到下边的屏幕。

`Ctrl + w k` -- 将当前的光标定位到上边的屏幕。

`Ctrl + w c` -- 关闭当前的分屏。

`Ctrl + w q` -- 关闭当前的分屏，如果是最后一个分屏将会退出 VIM 。

`Ctrl + w H` -- 将当前的分屏移动到左边。

`Ctrl + w L` -- 将当前的分屏移动到右边。

`Ctrl + w J` -- 将当前的分屏移动到下边。

`Ctrl + w K` -- 将当前的分屏移动到上边。

`zt` -- 当前行移动到当前屏幕的顶行。

`v` -- 可视化。

`V` -- 行可视化。

`ctrl + v` -- 块状可视化。

`:w Filename` **visual** 模式下，将选中内容另存为。

## Command Mode

`ESC` -- Back to Normal Mode.

`C-[` -- Back to Normal Mode

`:wq` -- 存盘 + 退出。

`:x` -- 保存并退出。

`:w` -- 存盘。(write)

`:e file` -- 打开新的文件。

`:q` -- 退出。(quit)

`:wq!` -- 强制保存并退出。

`:q!` -- 强制退出，丢弃改动。

`:qa!` -- 退出所有文件，丢弃所有改动。

`:w filename` -- 另存为。

`:e!` -- 放弃对文件的所有修改，恢复文件到上次保存的位置。

`:saveas filename` -- 另存为。

`:ls` -- 列出 `vim` 打开的所有文件。

`:bm` -- 切换到文件序号为 `m` 的文件。

`:bn` -- 切换下一个文件。(next)

`:bp` -- 切换上一个文件。(previous)

`:n` -- 切换下一个文件。

`:s/old/new/g` -- 替换命令，替换 old 为 new。(global)

`:s/old/new` -- 替换光标所在行的第一个匹配串。

`:s/old/new/g` -- 替换光标所在行所有匹配串。

`:#,#s/old/new/g` -- #，#代表行号，替换两行之间的匹配串。

`:%s/old/new/g` -- 替换整个文件中的所有匹配串。

`:%s/old/new/gc` -- 替换整个文件的所有匹配串，并询问用户确认每个替换。

`:%s/old/new/gi` -- 大小写不敏感查找，`I` 表示大小写敏感查找。

`:! command` -- 执行外部命令 command

`:n1,n2d` -- `n1` 和 `n2` 指的是起始行号和结束行号，`d` 是删除关键字。

`:r file` -- 提取文件 file 的内容，置入光标所在位置。

`:r !command` -- 可以将命令的输出置入光标所在位置。

`:set xxx` -- 对 vim 进行设置。

`:sp filename` -- 上下分割当前的文件和新打开的文件 `Filename`。（spilt）

`:vsp filename` -- 左右分割当前打开的文件和新打开的文件`filename`。

`tab` -- 命令补全。

`:help <command>` -- 显示相关命令的帮助，退出帮助为 `:q`。

`K` - 查看光标所指标识符的 man 帮助页。

`read ! xxx` - 读取命令执行结果

`J` - 合并两行

`!ls` -- 列出缓冲区状态

`vsp .` -- 打开当前目录

`jumps` -- 打开跳转表
    - `C-o` -- 跳回到上一个位置。
    - `C-i` -- 跳转到下一个位置。

`C-6` -- 返回上一个缓冲区。
`:b#` -- 返回上一个缓冲区。

`:vertical res 20` -- 设置窗口的分屏宽度。
